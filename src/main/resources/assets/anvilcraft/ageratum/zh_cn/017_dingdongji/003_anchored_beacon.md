# 铭化信标

<item id="dingdongji:anchored_beacon"/>

- 蕴含着磅礴的知识魔力，凋灵之力被其彻底转化
- 光柱可净化上方所有实体的负面效果
- 获取方式同腐化信标，但是是附魔金版本

## 光柱内的生物转化

- 铭化信标的魔力可将强大的怪物弱化，将部分生物净化

## 时定

- 凝滞其光柱上方的处于不同温度阶段方块，让其质能状态被稳定在当前阶段，光柱所射到的方块为中心的5x5x5范围的方块皆能受到时定影响

## 注魔和祛咒

- 将带有附魔或诅咒的物品丢入光柱后，该物品将被铭化信标按时间进行一次注魔和祛咒，注魔为随机选中一种附魔使其提升一级，附魔等级可突破附魔等级上限，祛咒则是随机选中一种诅咒使其降低一级；注魔和祛咒的时间受层数和是否为重质附魔金块影响

| 层数 | 附魔金块/重质附魔金块 |
|:--:|:--:|
| 1 层 | 120s/80s |
| 2 层 | 100s/55s |
| 3 层 | 80s/35s |
| 4 层 | 60s/20s |
