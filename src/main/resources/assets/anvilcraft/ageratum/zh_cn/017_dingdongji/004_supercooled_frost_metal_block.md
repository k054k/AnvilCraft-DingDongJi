# 过冷状态

<row halign="center">
<item id="anvilcraft:frost_metal_block"/>
<item id="dingdongji:supercooled_frost_metal_block"/>
</row>

- 极低的温度打破了它的质能平衡，注入质量会突破为超限合金，升温后有可能劣化为皇家钢块

# 原理

- 在时定锁定晶格结构的基础上，不断注入魔力并包裹住浮霜金属块仅余的微小能量，并通过浮霜砂轮将魔力连同包裹着的运动的粒子和能量一起祛除，不断接近绝对零度，最终制成
